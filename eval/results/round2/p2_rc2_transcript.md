**DRAFT, my plain explanation for Jamal** (how PubMed reads a search; no counts or findings):

- `[tiab]`: PubMed looks for the word only in the title and abstract. We pair it with `[Mesh]` subject headings because indexers add headings some time after a record appears, and some records never get them. The title and abstract words catch those records.
- `*` is truncation. It stands for any ending of the word, so one short stem covers many forms:

| As written | Would match, for example |
|---|---|
| `child*[tiab]` | child, children, childhood, and also childbirth |
| `vaccin*[tiab]` | vaccine, vaccines, vaccination, vaccinated |
| `anxi*[tiab]` | anxiety, anxious, and also anxiolytic (a drug that eases anxiety) |

So a star can also pull in words we don't want. We will check that when we build the full search (Step 8, Search Strategy).
